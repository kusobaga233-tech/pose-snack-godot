## 一、已经确认的硬性差异（不可能"照搬"的）

这三条是平台决定的，不是实现偷懒，必须先定策略：

| # | 差异 | 原因 | 选项 |
| --- | --- | --- | --- |
| 1 | **相机画面**：网页是"全屏相机背景 + 抠像/骨骼叠加"，Godot 现在是**右下角画中画浮层** | SDK 的系统上屏接口是 `TYPE_APPLICATION_OVERLAY`，**只能盖在应用之上**，没有"画在应用之下"的能力 | A. 保留画中画（低成本）<br>B. 走 NDK：`getFrameBuffer()` 拿 YUV420 HardwareBuffer，自己转 RGBA 上传成 Godot 纹理，才能真正做背景（成本 L） |
| 2 | **体感来源**：网页用 MediaPipe（33 点，浏览器内 WASM），Godot 用 Youdoo SDK（18 点，设备原生推理） | 平台要求走 SDK | 保持 SDK；但**映射参数**（圆心 0.35、死区、距离→速度曲线、丢失保持）必须逐项对齐网页版 |
| 3 | **玻璃拟态（backdrop-blur）**：网页面板用 `backdrop-filter: blur(14px)`，Godot GL Compatibility 没有便宜的背景模糊 | 渲染器差异 | A. 用半透明+描边+内发光"近似"（成本 S）<br>B. 用 SubViewport 抓背景做模糊（成本 M，有性能风险） |

## 七、盘点回来的三处口径纠正（2026-11-13，依据 `PARITY-INVENTORY.md`）
1. **小地图不是缺口，是我们多做的**：`drawMinimap` 在网页版是**死代码**（`main.js` 从不 import，`render.js:898` 只有定义）。
   → Godot 的小地图属于 `extra-in-godot`，保留或删除由产品定，不应算作"还原差距"。
2. **规则层已经是 1:1 移植**（`config.gd` 自称 1:1 + 404 断言），差距**几乎全在表现层/界面/输入/调试工具**，不在玩法。
   → 因此"完全还原"的主要工作量是美术与界面，不是规则。
3. **相机不再是"必须 NDK"的大工程**：现行网页版自己也只是**顶部界面带里一个 320×180 的镜像取景框**，不是全屏背景。
   → 我们现有的系统浮层（`setCameraLiveOnScreen`）**足够还原**：只要把矩形调到那个位置和大小、并解决镜像方向。
   → NDK 全屏背景从"必做"降级为"可选增强"（网页版本来也没有）。

## 九、不该照搬的（技术性劝退）

- 网页**逐帧 canvas 画蛇身**（5 遍 stroke + 逐节弧 + `shadowBlur`）——这正是 WebView 壳 1.5fps 的根因；**还原观感，不还原实现**。
- 12 项实时滑杆 + localStorage —— 遥控器不可达；做「上下换项 / 左右调值」的 8 项面板即可。
- 浏览器启动看门狗、`diag.js` 九类相机错误、体感日志下载 UI —— APK 里没有落点。
- 触摸拖拽、鼠标、手机视野公式、手机键位条 —— 盒子上永不触发。
- **全屏摄像头背景当必做项** —— 网页版自己也只有 320×180 镜像框（见七.3）。

## 十、便宜且该马上做的

静音按钮（现在无 UI）、历史最佳持久化（全工程无 `user://` 写入）、规则说明页、无尽模式入口、文案修正（模式卡「独自挑战 8 个 AI」应为 7 个）。



1. **自撞**：**维持"撞自己不死"**，并且自撞重叠时**必须是上层图层覆盖下层图层**（后画的盖住先画的，不能半透明混叠）。
   → 渲染要求：蛇身按段顺序绘制、填充不透明，蛇头最后画；重叠处必须是"实心遮挡"而不是"透出后面的身体"。
2. **相机**：**先看 SDK 自己怎么处理，然后照做一样的处理**。
   → 先只读研究 SDK 的 `CameraImage` 全链路（`FrameworkCameraImagePresentation`、`AndroidTextureBridgeVulkanCutout`、`CameraImageUvRegionUtility` 等）：帧从哪来、怎么镜像、抠像/alpha 怎么出、画在应用之下还是之上。
   → 结论如果是"SDK 用原生纹理桥把帧变成 Unity 纹理再当背景画"，那 Godot 侧就照这个思路走（`getFrameBuffer` → NDK 转 RGBA → Godot 纹理），而不是继续用系统浮层。
3. **设置面板**：**只作内部调试**，并**在打包时可配置是否显示**（构建期开关，默认不显示；开启后可用按键/参数打开）。
